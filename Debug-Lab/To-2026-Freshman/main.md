## 实验室简介

### 我们是做什么的？

DEBUG 实验室成立于 2012 年，隶属于**浙大城市学院信息与电气工程学院**，由信电实验中心和 DEBUG 团队联合培养。我们面向全校招收人才，成员以信电学院、计算学院的学生为主，同时也欢迎各学院的同学参加。

DEBUG 致力于培养培养具备卓越工程能力、团队协作精神的优秀青年工程师。方向涵盖机器人、嵌入式、电气电子等等方面。

我们主要组织、培养团队成员参加**大学生电子设计竞赛**、**大学生智能汽车竞赛**、**大学生嵌入式芯片与系统设计竞赛**、**大学生机器人竞赛**等一系列电气电子、机器人方向国家级省级赛事。

竞赛之外，我们也鼓励同学们自由选题，产出一定量的**科研、科创成果**。

### 零基础可以加入吗？

DEBUG 实验室**超过 90% 的同学都是从零基础新生一路走来**。

即使你从未接触过编程、电子、机械等等方面的知识，只要你拥有出色的自学能力，热爱技术与工程，勤于思考学习探索，喜欢电子与机器人，想获得一个有理想有奋斗目标的大学四年，想学点课堂与书本以外的不一样的工程知识，想接触新时代的技术浪潮等等，就具备足够的资质。

因此加入实验室并不需要具备足够的基础。在开学初我们会组织培训以及选拔，选拔出具备足够资质的同学进入实验室。

### 能在这获得什么？

#### 平台

实验室聚集了学校历年来培养的最为优秀的一批学长学姐，走出了一批又一批的优秀工程师。

不论你后续打算考研升学还是直接就业，都能在这里通过和学长的交流获得足够的经验。

参与电赛、智能车等诸如此类的全国性竞赛，也能够接触到远广于校内的技术交流社区，和全国各地的优秀选手共同交流进步。

#### 技术

在这里你将学习到远广于课内知识以及工程经验。

通过一个又一个的项目的调试，你能够获得相比学校课堂以外成倍的实践与项目经验。

在这里你会接触各类工业常用的主控芯片以及平台的开发，接触控制、视觉等等算法，接触机械设计、接触电气电子工程、接触 AI 等等业内的常用技术与前沿技术。

#### 资金

实验室的竞赛经费虽然谈不上毫无限制，但是绝对是充足的。

除此之外，学校还为参加竞赛获奖开设了专门的奖学金项目：

《浙大城市学院本科学生奖学金评定条件及 管理办法（2025 年 6 月修订）》

（3）学科竞赛优秀奖学金 用于奖励在各类学科竞赛（竞赛种类和级别主要依据教务部 公布的年度学校学科竞赛赛项）方面取得优秀成绩的个人或团队， 分一等、二等两个等级，根据获奖证书认定。具体条件如下：

①一等奖个人奖励金额 1500 元，团队奖励 3000 元，必须符 合下列条件之一： 获学校公布的 A 类或 B 类学科竞赛三等奖以上奖项。

②二等奖个人奖励金额 800 元，团队奖励 1500 元，必须符合 下列条件之一： 获学校公布的 C 类学科竞赛一、二等奖，或校级学科竞赛一 等奖。 一个学生或团体获多项竞赛奖的按照最高奖励级别评定

比赛获奖还有专项的奖金：

《浙大城市学院学科竞赛奖励办法 （2023 年 8 月修订）》

第二章 第九条　对参赛获奖学生的奖励 （一）对在 A 类赛事竞赛中获奖的学生给予现金奖励，并在 获奖当学年对获奖学生在奖学金评定时的平均学分绩点（GPA）予 以加分奖励；在 B 类赛事国际级、国家级竞赛获奖的学生，现金 奖励和平均学分绩点（GPA）奖励按省级竞赛进行，其余赛事不进行现金奖励和平均学分绩点（GPA）加分奖励。奖励标准见附件。

具体来说就是这样的：

|   |   |   |   |
|---|---|---|---|
|竞赛级别|获奖等级|GPA 奖励上限|现金奖励（万元 / 队）|
|国家级竞赛（含国际级）|特等奖|0.6|1.5|
|国家级竞赛（含国际级）|全国一等奖|0.5|1|
|国家级竞赛（含国际级）|全国二等奖|0.3|0.6|
|国家级竞赛（含国际级）|全国三等奖|0.2|0.3|

我们上述的所有比赛都属于 “学校公布的 A 类或 B 类学科竞赛”，因此基本上只要拿奖就能拿到学科竞赛奖学金。

因此，我本人在大一的时候甚至拿了一份个人四份团队竞赛优秀一等奖学金。最终能拿到的金额就是上面说的按照奖项发的奖金 + 按照团队发的奖学金。

## 劝退环节

“99% 的人在这里被打败，100% 的人在这里收获成长。”

学习与成长的道路终究是艰难的。加入 DEBUG，就意味着你为你的大学生活选择了一条并不十分好走的路。

“遗憾是智能车的主旋律”，努力了几年拿不到一个心仪的奖项是十分正常的事情。在 DEBUG 学习到的各类知识也未必会对你考研、考公、考各种证、卷绩点、升学有直接帮助。

DEBUG 的同学在课外花费了大量的时间，设计、试错、钻研，然后收获成长。光鲜亮丽的履历背后，是他们花费大量的课外时间甚至用课内时间翘课泡实验室换来的。

是的，参加实验室的确会占用较多的课余时间，对于时间控制能力较差的同学来说会影响课内学习。但是实验室中也不乏合理安排个人时间，最后竞赛绩点两开花的同学，主要取决于个人对时间的把控力。（顺带一提由于我们学校没有保研，在我们学校绩点除了评奖学金以外没有任何用处）

在 DEBUG，你能学习接触到最前沿的技术、大学最有活力的技术圈子，而你稳定收获的也只有技术、经验、项目经历，以及不那么碌碌无为的大学四年。

祝你好运🫡

## 加入我们

DEBUG 欢迎来自各专业、各年级的同学加入。

每年 9 月份 DEBUG 都会开展开展招新培训以及招新考核。

只要通过招新考核，即可加入 DEBUG 实验室。
