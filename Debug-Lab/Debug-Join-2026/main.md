2026 年 DEBUG 实验室通过招新赛题和正式面试进行考核，同时为报名同学提供统一培训。我们希望通过这套流程，找到真正热爱技术、愿意主动探索，并能持续学习和解决问题的同学。

我们期待你具备以下品质：

1. 较强的自学能力
2. 充足的内驱力与上进心
3. 好奇心与求知欲
4. 搜索、判断、筛选和处理信息的能力
5. 分析、设计和解决复杂问题的能力

## 考核流程

招新考核分为提前批和正式批，具体流程如下：

1. 开学第二周发布招新赛题。
2. **提前批：** 在培训结束前满分完成招新赛题，即可在验收后参加正式面试。
3. **正式批：** 培训结束后统一验收招新赛题；达到 60 分即可在验收后参加正式面试，通过面试者按赛题成绩参与正式批排名。
4. 根据各组剩余名额确定正式批录取名单。

我们希望通过招新**发掘自学能力强的同学**，因此提前批与正式批不分别预留名额，而是**共享各组的录取名额**。通过提前批录取的同学会直接占用该组名额。

这项规则会让主动自学、尽早完成赛题的同学优先获得面试和录取机会，从而鼓励大家选择提前批。相应地，如果等到培训结束后才参加正式批，本组名额可能不足，甚至已经录满。

## 招新组别

- **软件组：** 负责嵌入式系统、控制与感知算法的软件研发。主要学习计算机与嵌入式基础、裸机开发、RTOS、Linux 开发、通信与系统调试、控制算法、视觉算法和上位机开发。
- **硬件组：** 负责电子系统的设计、实现与调试。主要学习模数电路基础、电源与驱动电路、传感器与通信接口、原理图与 PCB 设计、元器件选型、焊接装配，以及硬件测试与故障排查。
- **机械组：** 负责机械结构与传动系统的设计、仿真、制造和装配调试。主要学习机械设计基础、机构与传动设计、轮系与轴系设计、工程制图与公差配合、结构与强度仿真，以及 3D 打印、CNC、钣金、碳纤维等结构件的设计与制造。

三个组别是不同的招新赛道，并非实验室内部的固定分工。我们鼓励大家学习其他组别的知识，探索多学科交叉的可能。在实际组队中，一名成员也可能同时承担软件、硬件或机械方向的工作。

## 招新名额

DEBUG 实验室计划从大一同学中招收不超过 **12 人**，提前批与正式批共享名额。

各组暂定名额如下，实际名额会根据报名情况动态调整：

|   |   |
|---|---|
|组别|名额（暂定）|
|软件组|6 人|
|硬件组|3 人|
|机械组|3 人|

- **提前批：** 以满分验收通过时间为排序依据；通过面试后，按该顺序录取。我们鼓励大家主动自学，尽早完成招新赛题并参加面试。考虑到各组赛题难度可能存在差异，每组均设有录取上限；某组通过提前批达到上限后，该组后续的提前批和正式批验收将不再产生有效录取。
- **一人多组：** 每名同学可以同时报名多个组别。例如，同时参加机械组和硬件组考核的同学，即使未被机械组录取，仍可通过硬件组考核争取录取资格。
- **调剂：** 某组提前批名额已满后，继续参加项目验收仍然有意义。如果其他组别尚有名额，我们可能根据各组报名和考核情况，将空余名额调剂至其他组别。调剂可能发生在完成面试的当周，也可能发生在全部组别培训结束的当周。

我们也欢迎大二、大三、专升本的同学加入 DEBUG。

**大二、大三同学**可以通过以下两种渠道参加招新：

1. **简历投递**： 提交个人简历，通过简历筛选后进入面试。
2. **参加招新考核**： 与大一同学参加相同的招新赛题，但验收时间会适当提前。验收满分通过即可进入面试。

面向大二、大三同学的报名方式、材料要求、验收安排和录取方式将在后续通知中公布。

对于**专升本**的同学，提交个人简历后，通过简历筛选即可进入面试。

未尽事宜将根据实际情况另行说明，最终解释权归 DEBUG 工作室所有。

## 培训安排

培训共 8 周，从开学第二周开始：

- 软件组在每个培训周的周一上课。
- 硬件组与机械组在周三交替上课：第一、三、五、七周为硬件组，第二、四、六、八周为机械组。

学校的大部分晚课集中在周二和周四，因此实验室将集中授课安排在周一和周三，让更多同学能够参加。

从开学第二周开始，8 个培训周内的周二、周四晚自习由实验室负责组织。已报名培训且当天没有晚课的同学仍需参加晚自习，具体签到与考勤方式以实验室和学院的最终通知为准。

晚自习以自主学习为主。实验室会定期安排成员到自习室答疑，可以利用这段时间推进招新赛题，或参加提前批验收。

晚自习的出勤管理不改变前文所述录取规则，录取仍以招新赛题完成情况、名额和面试结果为准。

培训内容与招新赛题在知识点上高度相关，但培训参与情况与录取结果没有直接关系。培训不是考核的必经环节，也不是获得录取资格的前提。

培训主要用于提供阶段性的学习节奏，让大家在共同学习和实践中获得参与感，并提前认识未来可能一起合作的同学。
